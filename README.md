# jovian-careers-website
A careers website for Jovian (freecodecamp project)

## Colossal Cave (in `adventure/`)

A remake of the original *Colossal Cave Adventure* ("Advent") with a map
that draws itself, an itinerary, an amber VT-100 terminal and pictures
painted in L. S. Lowry's five colours. It needs only Python 3.9+:

```
python3 adventure/play.py              # plays in your web browser
python3 adventure/play.py --terminal   # plays in this terminal
```

See [adventure/README.md](adventure/README.md) for more.
